# Fizz Health v1.4.16.10 — Podcast Playlists Foundation

## Scope delivered

- Added a third Podcasts folder tab named **Stories**.
- Added generic playlist, playlist subscription, and playlist item tables.
- Added a **Playlists** section to individual podcast settings.
- Added independent **Up Next** and **Stories** subscription checkboxes.
- Subscribed podcasts automatically add qualifying unplayed episodes during feed refresh.
- Preserved existing episode visibility and sort rules.
- Kept Stories non-autoplay while Up Next remains the sequential queue.
- Kept podcast settings independent from rendering large episode feeds.

## Out of scope

- Playlist subscription ordering.
- Drag-and-drop inside Stories.
- User-created playlists.
- Playlist search and artwork.
