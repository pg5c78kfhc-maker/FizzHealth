# Fizz Health v1.4.14.4 — Menu Information, Universal Categories, and Presentation

## FH-1414.10 — Menu Information View
A normal tap now opens a read-only Information page. Existing swipe actions remain available, and Add to Meals is launched only through the explicit action on the Information page or the established swipe action.

## FH-1414.11 — Universal Category Editing
Foods, restaurant items, meals, and recipes can be reclassified from Menu. Changes persist to the appropriate database table and the item moves immediately without a reload.

## FH-1414.12 — Experimental Menu Presentation Refresh
The interface below the gold Menu title uses a light restaurant-menu treatment. Header, calendar, Restaurant Day controls, macro cards, and navigation remain unchanged.
